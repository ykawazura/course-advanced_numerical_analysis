    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    演習1

    本章の三重対角 SPD 系 \(A = \mathrm{tridiag}(-1, 2, -1)\)、\(\mathbf{b} = (1, \dots, 1)^{\top}\) について、次元 \(n\) を \(10, 20, 40, 80\) と変えながら、ヤコビ法・ガウス＝ザイデル法・共役勾配法の収束までの反復回数を表にまとめよ。許容誤差は相対残差 \(10^{-8}\) とする。\(n\) を倍にすると各手法の反復回数はどう増えるか、考察せよ。

    ヒント
    • 定常反復法の jacobi / gauss_seidel と、共役勾配法の matvec / dot をそのまま使える。#define N 10 を外して次元を引数 n にすれば、同じ関数を \(n\) ごとに呼び出せる。
    • 3手法を1つのプログラムにまとめ、\(n\) のループで呼び出すと比較しやすい。CG は本文では main に直書きしてあるので、反復回数を返す関数にまとめておく。
    • 反復回数を \(n\) の関数として両対数で見ると、増え方（べき）が読み取れる。定常反復法は \(O(n^2)\)、CG は \(O(n)\) が予想される。

    演習2

    共役勾配法は対称正定値行列を前提とする。この前提が崩れると何が起こるかを実験で確かめよ。次の非対称な三重対角行列を考える。

    \[ A_\beta = \mathrm{tridiag}(-1-\beta,\ 2,\ -1+\beta) \]

    （1次元の移流拡散方程式を中心差分で離散化すると現れる形である。）\(\beta = 0\) なら対称正定値、\(\beta \neq 0\) なら非対称になる。\(\mathbf{b} = (1, \dots, 1)^{\top}\)、\(n = 20\) として、

    (a) \(\beta = 0\) と \(\beta = 0.8\) で CG を実行し、相対残差の推移を比較せよ。

    (b) なぜ非対称行列で CG が破綻するのか説明せよ。

    ヒント
    • 共役勾配法のコードをそのまま使い、build の副対角だけ \(-1\pm\beta\) に変える。CG の反復式には手を触れない。
    • \(\beta = 0\) では数ステップで残差が急落して収束するが、\(\beta = 0.8\) では残差が単調に増大して発散するはずである。
    • CG の導出で「対称正定値」をどこで使ったか（\(\alpha_k, \beta_k\) の最適性、\(A\)-共役性）を思い出すこと。

    解答（🔒 パスワードを入力すると表示）

    補足: 非対称・不定な系に使う反復法

    演習2 で見たように、\(A\) が対称正定値でなければ共役勾配法はそのまま使えない。今回は扱わないが、非対称・不定な系には次の方法を用いる。

    1. 非対称用クリロフ部分空間法: 非対称行列を直接扱える反復法を使う。代表的なものに GMRES（残差を最小化、メモリ消費が反復とともに増える）、BiCGSTAB、QMR などがある。実務では非対称疎行列に対してこれらが標準的に用いられる。
    2. 正規方程式（CGNR/CGNE）: \(A^{\top}A\mathbf{x} = A^{\top}\mathbf{b}\) は対称正定値なので CG が適用できる。ただし条件数が \(\kappa(A^{\top}A) = \kappa(A)^2\) と2乗に悪化し、収束が遅くなる欠点がある。
    3. 前処理の併用: いずれの方法でも、適切な前処理行列 \(M \approx A\) を併用して条件数を下げることが収束のために重要である。

    要点は、「CG は SPD 専用」であり、非対称・不定な系には専用のクリロフ法（GMRES・BiCGSTAB など）か正規方程式化を使う、ということである。
