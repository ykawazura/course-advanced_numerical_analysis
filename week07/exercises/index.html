    演習問題

    解答について

    演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、解答が表示される。

    演習は、撃ち抜き法のサンプルコードと有限差分法のサンプルコードを数行書き換えれば解ける。撃ち抜き法の長所と限界で述べた「初期傾きの誤差が指数的に増幅する方程式では、撃ち抜き法は破綻しやすい」を、係数 \(k\) を変えて目で確かめる。

    演習

    境界値問題

    \[ -y'' + k^2 y = (\pi^2+k^2)\sin(\pi x), \qquad y(0)=y(1)=0 \]

    を \(k=10\) と \(k=40\) について、撃ち抜き法（RK4、線形）と有限差分法（トーマス法）で \(N=50\) で解き、厳密解 \(y(x)=\sin(\pi x)\) と重ねて描け。両手法の最大誤差も示し、\(k=40\) で何が起きたかを述べよ。

    ヒント
    • rk4_step・shoot は撃ち抜き法のサンプルから、thomas は有限差分法のサンプルからそのまま写せばよい。書き換えるのは、rhs の ds[1] の1行と、差分の係数 b[i]・d[i] の2行である。
    • rhs の引数の形は rk4_step が決めているので、\(k\) は引数では渡せない。ファイルの先頭に static double K を置き、main で値を変えればよい。
    • 解を描くには格子点の値が要る。C で ex1.dat に書き出し、有限差分法の可視化と同じく Python で読んで描けばよい。
