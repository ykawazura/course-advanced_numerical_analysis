    演習問題

    解答について

    演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、解答が表示される。

    演習は、撃ち抜き法のサンプルコードと有限差分法のサンプルコードを数行書き換えれば解ける。撃ち抜き法の長所と限界で述べた「初期傾きの誤差が指数的に増幅する方程式では、撃ち抜き法は破綻しやすい」を、係数 \(k\) を変えて確かめ、撃ち抜き法と有限差分法のどちらが得かを比べる。

    演習

    境界値問題

    \[ -y'' + k^2 y = (\pi^2+k^2)\sin(\pi x), \qquad y(0)=y(1)=0 \]

    を、撃ち抜き法（RK4、線形）と有限差分法（トーマス法）で解く。厳密解は \(k\) によらず \(y(x)=\sin(\pi x)\) で、\(k=0\) のときは例題1になる。斉次方程式 \(y''=k^2y\) の解は \(e^{kx}\) と \(e^{-kx}\) で、\(k\) が大きいほど \(e^{kx}\) は区間 \([0,1]\) で急に増える。

    手間は右辺の関数 \(f(x)=(\pi^2+k^2)\sin(\pi x)\) の評価回数 \(n_f\) で数える。撃ち抜き法は傾き \(0,\ 1,\ s^*\) の3回をそれぞれ \(N\) ステップの RK4 で撃つので \(n_f=12N\)、有限差分法は内点の数だけ評価するので \(n_f=N-1\) である。誤差を測るための厳密解の計算と、トーマス法の演算は数えない。

    (a) 初期傾き \(s\) が \(\delta s\) だけずれると、解は \(\delta s\,\sinh(kx)/k\) だけずれることを示せ。倍精度の丸め1回分 \(\delta s\approx10^{-16}\) のずれが \(x=1\) で \(10^{-8}\) を超える \(k\) の目安を求めよ。

    (b) \(k=0,\ 10,\ 15,\ 30,\ 40\) のそれぞれで、最大誤差が \(10^{-8}\) 以下になる最小の \(N\) と \(n_f\) を両手法で求めよ。撃ち抜き法は \(N\le1000\) の範囲で探し、\(N=1000\) での最大誤差も示して (a) と比べよ。撃ち抜き法と有限差分法のどちらが得かは何で決まるかを答えよ。

    ヒント
    • rk4_step・shoot は撃ち抜き法のサンプルから、thomas・fd_maxerr は有限差分法のサンプルから写せばよい。書き換えるのは、rhs_lin の ds[1] の1行と、fd_maxerr の b[i]・d[i] の2行である。
    • rhs_lin の引数の形は rk4_step が決めているので、\(k\) は引数では渡せない。ファイルの先頭に static double K を置き、main で値を変えればよい。
    • (a) の2つの解の差 \(u\) は、\(u''=k^2u\) を \(u(0)=0,\ u'(0)=\delta s\) で解いたものである。
