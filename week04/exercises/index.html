    演習問題

    解答について

    演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、解答が表示される。

    この演習は、ルンゲ＝クッタ法の調和振動子のプログラム oscillator.c をもとにする。1ステップの関数 rk4_step は名前も中身も変えずにそのまま写し、右辺 rhs と保存量 energy だけを問題に合わせて替える。線形の調和振動子では起きない、振幅によって周期が変わる現象を、数値と図の両方で確かめるのがねらいである。

    演習

    ルンゲ＝クッタ法で解いた調和振動子は、振り子の振れが小さいときの線形近似である。実際の単振り子は非線形の方程式

    \[ \theta'' = -\frac{g}{L}\sin\theta \]

    に従う（\(\theta\) は鉛直からの振れ角）。ここでは軽い棒でつるした振り子を考え、簡単のため \(g/L = 1\) とする。これを \(x = \theta,\ \omega = \theta'\) とおいて1階連立系 \(x' = \omega,\ \omega' = -\sin x\) に直し、静止状態（\(\theta = \theta_0,\ \theta' = 0\)）から放った運動を RK4 で解け。

    (a) 保存量（力学的エネルギー）\(E = \tfrac12\,\theta'^2 - \cos\theta\) が保たれることを確認し、解の精度を裏づけよ。

    (b) 小振幅（\(\theta_0 = 0.1\)）では、周期が線形近似（調和振動子）の値 \(T_0 = 2\pi\sqrt{L/g} = 2\pi\) にほぼ一致することを確認せよ。

    (c) \(\theta_0 = 0.1,\ 1.0,\ 2.0,\ 3.0\) のそれぞれについて、\(0 \leq t \leq 20\) の軌道を2通りに描け。1つは振幅で割った振れ角 \(\theta/\theta_0\) の時間変化、もう1つは相平面 \((\theta, \theta')\) 上の軌道である。振幅によって周期がどう変わるかを、これらの図と周期の値を使って説明せよ。

    ヒント
    • 周期の測り方: 静止状態から放つと運動は対称なので、\(\theta\) が初めて \(0\) を横切る時刻が \(1/4\) 周期。線形補間で交点の時刻を精密に求め、4倍すればよい。
    • エネルギーの変動 \(\max E - \min E\) を見れば、RK4 の精度（保存則の破れの小ささ）が分かる。十分小さい \(h\)（たとえば \(10^{-3}\)）を使う。
    • \(\pi\) は M_PI（環境により未定義）に頼らず static const double PI = 3.14159265358979323846; と自分で定義する。
    • 軌道は、各時刻の \((t, \theta, \theta')\) をファイルに書き出し、Python で描く。オイラー法の可視化と同じ手順である。
    • 相平面には、エネルギーが \(E = 1\) の曲線（真上 \(\theta = \pm\pi\) でちょうど止まる運動）を重ねるとよい。
