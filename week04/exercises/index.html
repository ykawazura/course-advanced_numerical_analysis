    演習問題

    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    いずれの演習も、オイラー法・ルンゲ＝クッタ法のサンプルコードを土台にすればよい。数値解と厳密解（または保存量）の差を測り、刻み幅を変えたときの振る舞いを観察するのが共通のねらいである。

    演習1（基礎）

    例題1（\(y' = y - t^2 + 1\)、\(y(0) = 0.5\)、厳密解 \(y(t) = (t+1)^2 - \tfrac12 e^t\)）を前進オイラー法で、\(h = 0.2\) と \(h = 0.1\) の2通りで \(t = 2\) まで解け。

    (a) それぞれの \(t = 2\) での数値解と、厳密解 \(y(2) = 9 - \tfrac12 e^2 \approx 5.305472\) との誤差を求めよ。

    (b) 刻みを半分にしたとき誤差がどう変わるかを誤差比で示し、前進オイラー法が1次精度であることを確認せよ。

    ヒント
    • オイラー法のサンプルコードをそのまま使い、\(h\) を変えて \(t=2\) の値だけ取り出せばよい。
    • 大域誤差は \(O(h)\) なので、\(h\) を半分にすると誤差はおよそ半分（誤差比 \(\approx 2\)）になるはずである。
    • ステップ数は \(N = 2/h\)。浮動小数点の誤差を避けるため N = (int)(2.0/h + 0.5) のように整数化するとよい。

    解答（🔒 パスワードを入力すると表示）

    演習2（基礎）

    ホイン法（改良オイラー法・RK2）

    \[ k_1 = f(t_n, y_n), \quad k_2 = f(t_n + h,\ y_n + h\,k_1), \quad y_{n+1} = y_n + \tfrac{h}{2}(k_1 + k_2) \]

    を実装し、例題1を \(h = 0.2,\ 0.1,\ 0.05\) で解け。\(t = 2\) での誤差と誤差比を求め、ホイン法が2次精度である（刻みを半分にすると誤差が約 \(1/4\)）ことを確認せよ。演習1の前進オイラー法の結果と比べ、同じ刻みでどれだけ精度が上がるかを述べよ。

    ヒント
    • ホイン法はルンゲ＝クッタ法ページの2次の式そのもの。1ステップで \(f\) を2回評価する。
    • 2次精度なら大域誤差は \(O(h^2)\) なので、\(h\) を半分にすると誤差は \(1/2^2 = 1/4\)、誤差比は約 \(4\) になる。

    解答（🔒 パスワードを入力すると表示）

    演習3（応用）

    例題2の調和振動子 \(y'' = -y\)（\(y(0)=1,\ y'(0)=0\)）を、\(u = y,\ v = y'\) とおいて1階連立系 \(u' = v,\ v' = -u\) に直し、前進オイラー法と RK4 の両方で長時間（たとえば \(t = 50\) まで）積分せよ。

    (a) 保存量 \(E = \tfrac12(u^2 + v^2)\) の時間変化を両手法で比較し、表またはグラフで示せ。厳密には \(E = \tfrac12\) で一定である。

    (b) 前進オイラー法では \(E\) がどのように変化するか。1ステップで \(E\) がちょうど \((1 + h^2)\) 倍になることを、式の上で確かめよ。

    (c) RK4 の結果と比べ、振動・保存系では手法の選択がなぜ重要かを論ぜよ。

    ヒント
    • ルンゲ＝クッタ法ページの系のサンプルコードをそのまま使い、積分時間を延ばせばよい。状態は double s[2] = {u, v}。
    • (b) 前進オイラーの1ステップは \((u, v) \to (u + hv,\ v - hu)\)。新しい \(u^2 + v^2\) を展開すると交差項が消えて \((1 + h^2)(u^2 + v^2)\) になる。
    • エネルギーが毎ステップ \((1+h^2)\) 倍なら、\(n\) ステップ後は \((1+h^2)^n\) 倍。これは時間とともに指数的に増大する。
    • (c) RK4 の \(E\) も8桁目を見ると動いている。増えているか減っているか、そして「一定」と言い切ってよいかに注目せよ。

    演習4（発展）

    調和振動子は線形近似だったが、実際の単振り子は非線形の方程式

    \[ \theta'' = -\frac{g}{L}\sin\theta \]

    に従う（\(\theta\) は鉛直からの振れ角）。ここでは簡単のため \(g/L = 1\) とする。これを \(x = \theta,\ \omega = \theta'\) とおいて1階連立系 \(x' = \omega,\ \omega' = -\sin x\) に直し、静止状態（\(\theta = \theta_0,\ \theta' = 0\)）から放った運動を RK4 で解け。

    (a) 保存量（力学的エネルギー）\(E = \tfrac12\,\theta'^2 - \cos\theta\) が保たれることを確認し、解の精度を裏づけよ。

    (b) 小振幅（\(\theta_0 = 0.1\)）では、周期が線形近似（調和振動子）の値 \(T_0 = 2\pi\sqrt{L/g} = 2\pi\) にほぼ一致することを確認せよ。

    (c) 振幅を \(\theta_0 = 1.0,\ 2.0,\ 3.0\) と大きくすると、周期がどう変わるかを観察し、論ぜよ。

    ヒント
    • 周期の測り方: 静止状態から放つと運動は対称なので、\(\theta\) が初めて \(0\) を横切る時刻が \(1/4\) 周期。線形補間で交点の時刻を精密に求め、4倍すればよい。
    • エネルギーの変動 \(\max E - \min E\) を見れば、RK4 の精度（保存則の破れの小ささ）が分かる。十分小さい \(h\)（たとえば \(10^{-3}\)）を使う。
    • \(\pi\) は M_PI（環境により未定義）に頼らず static const double PI = 3.14159265358979323846; と自分で定義する。
