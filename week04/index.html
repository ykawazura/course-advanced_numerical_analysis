    第4回: 常微分方程式の初期値問題

    今回の目標

    • 常微分方程式（ODE）の初期値問題（initial value problem, IVP）とは何かを理解する
    • 最も基本的な数値解法である前進オイラー法を導出し、自分で実装できるようになる
    • 多点で傾きを評価して精度を上げるルンゲ＝クッタ法（Runge–Kutta method）、とくに2次のホイン法と4次の古典的 RK4 を理解する
    • 高階の方程式を1階の連立系に直す手法を身につけ、ベクトルのまま同じ解法を適用できることを理解する
    • 解法の良し悪しを測る収束次数（order of accuracy）の概念を、数値実験で体感する

    常微分方程式はどこに現れるか

    時間とともに変化する量の「変化の速さ」が、その量自身の関数として与えられているとき、その関係式は常微分方程式になる。たとえば次のような場面である。

    • 力学: ニュートンの運動方程式 \(m\ddot{x} = F(x, \dot x, t)\)。惑星の軌道、振り子、ばねの振動。
    • 化学・生物: 反応速度式 \(\dot{c} = -kc\)、個体数の増減（ロジスティック方程式）、感染症の SIR モデル。
    • 電気回路: コンデンサ・コイルを含む回路の電流・電圧の時間変化。
    • 偏微分方程式の半離散化: 本講義後半で扱う拡散方程式・移流方程式は、空間を離散化すると時間についての大きな連立常微分方程式になる（線の方法, method of lines）。

    これらの多くは解析的に解けない。そこで、初期状態から時間を少しずつ進めて解を数値的に追跡する方法が必要になる。

    初期値問題の一般形

    未知関数 \(y(t)\) についての1階常微分方程式の初期値問題は、次の形に書ける。

    \[ \frac{dy}{dt} = f(t, y), \qquad y(t_0) = y_0. \]

    右辺 \(f(t, y)\) は「いまの時刻 \(t\) と値 \(y\) が分かれば、変化の速さ（傾き）が分かる」ことを表す。初期値 \(y_0\) を与えれば、解曲線は一意に定まる（\(f\) が滑らかなら）。

    未知関数が複数あるときは、ベクトル \(\mathbf{y} = (y_1, \dots, y_m)^\top\) とベクトル値関数 \(\mathbf{f}\) を使って

    \[ \frac{d\mathbf{y}}{dt} = \mathbf{f}(t, \mathbf{y}), \qquad \mathbf{y}(t_0) = \mathbf{y}_0 \]

    と書く。スカラーの場合の式をそのままベクトルに読み替えればよく、後で学ぶ解法はすべてこのベクトル形のまま成り立つ。

    離散化の考え方

    解 \(y(t)\) を区間 \([t_0, t_{\text{end}}]\) で求めたい。連続な時間を、刻み幅（step size）\(h\) で区切った離散的な時刻

    \[ t_n = t_0 + n h \qquad (n = 0, 1, 2, \dots) \]

    の上で考え、真の値 \(y(t_n)\) の近似 \(y_n\) を、\(y_0\) から1つずつ前へ進めて計算する。\(y_n\) から \(y_{n+1}\) を求めるのに直前の1点だけを使う方法を1段法（one-step method）と呼ぶ。今回扱うオイラー法もルンゲ＝クッタ法も1段法である（複数の過去点を使う多段法は第5回で扱う）。

    高階の方程式を1階の連立系に直す

    運動方程式のような2階以上の微分方程式も、新しい変数を導入して1階の連立系に書き直せる。これにより、1階の方程式に対して作った解法を、そのまま高階の問題に使える。

    たとえば2階の方程式 \(y'' = g(t, y, y')\) は、\(v = y'\) という変数を導入すると

    \[ \begin{cases} \ y' = v \\ \ v' = g(t, y, v) \end{cases} \qquad\Longleftrightarrow\qquad \frac{d}{dt}\begin{pmatrix} y \\ v \end{pmatrix} = \begin{pmatrix} v \\ g(t, y, v) \end{pmatrix} \]

    という、未知数2つの1階連立系になる。\(n\) 階の方程式なら \(n\) 個の1階方程式の系になる。「高階 → 1階の系 → ベクトルのまま数値解法」という流れは、常微分方程式の数値計算の定石である。

    本章を貫く2つの例題

    各手法を同じ問題で比較するため、次の2つを共通の例題として用いる。

    例題1: 厳密解のあるスカラー問題

    \[ y' = y - t^2 + 1, \qquad y(0) = 0.5, \qquad t \in [0, 2]. \]

    この問題には厳密解が閉形式で分かるという大きな利点がある。

    \[ y(t) = (t+1)^2 - \tfrac{1}{2} e^{t}, \qquad y(2) = 9 - \tfrac{1}{2} e^2 \approx 5.305472. \]

    （\(y(0) = 1 - 0.5 = 0.5\) で初期条件を満たす。）数値解と厳密解の差を誤差として測れるので、各手法の精度や収束次数を定量的に評価できる。数値解析の教科書（Burden & Faires など）でも定番の例題である。

    例題2: 高階を1階化した連立系（調和振動子）

    ばねや単振り子の小振幅振動を表す調和振動子 \(y'' = -y\) を、\(u = y\)、\(v = y'\) とおいて1階連立系に直す。

    \[ \begin{cases} \ u' = v \\ \ v' = -u \end{cases}, \qquad u(0) = 1, \ v(0) = 0. \]

    厳密解は \(u(t) = \cos t\)、\(v(t) = -\sin t\) で、相平面 \((u, v)\) では半径1の円を回り続ける。さらに、エネルギーに相当する保存量

    \[ E = \tfrac{1}{2}\left(u^2 + v^2\right) = \tfrac{1}{2} \quad (\text{一定}) \]

    をもつ。この \(E\) が数値計算でどれだけ保たれるかを見ると、手法の質がはっきり可視化できる。後述のように、前進オイラー法では \(E\) が時間とともに増大して解が外へ渦巻くのに対し、RK4 では \(E\) の誤差が桁違いに小さい。ただし RK4 も \(E\) を厳密に保存するわけではなく、ごくゆっくりと単調に減少する（ルンゲ＝クッタ法）。連立系・高階問題への動機づけと、解法の優劣の比較に用いる。

    各ページ・演習

    • オイラー法 — 最も基本的な1段法。導出・幾何的意味・1次精度・実装
    • ルンゲ＝クッタ法 — ホイン法（2次）と RK4（4次）・連立系への拡張・調和振動子
    • 精度と収束次数 — 局所誤差と大域誤差・次数 \(p\)・誤差比による次数の測定
    • 演習問題 — 非線形振り子の周期と軌道
