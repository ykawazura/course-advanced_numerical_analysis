    Visual Studio Community 環境構築

    Visual Studio Community を使って、Windows 上に C の開発環境を構築する。

    macOS / Linux ユーザーへ

    Visual Studio Community は Windows 専用である。macOS / Linux ユーザーは マニュアルインストール を参照すること。

    Visual Studio Community のインストール

    1. Visual Studio Community のダウンロードページからインストーラをダウンロードする

    2. インストーラを起動し、ワークロードの選択画面で 「C++ によるデスクトップ開発」 にチェックを入れる

      ワークロードの選択

      「C++ によるデスクトップ開発」を選択しないと C コンパイラがインストールされない。必ずチェックを入れること。

    3. 「インストール」をクリックし、完了するまで待つ

    プロジェクトの作成

    1. Visual Studio を起動し、「新しいプロジェクトの作成」を選択する
    2. テンプレートの検索で「空のプロジェクト」を選び、言語フィルタで C++ を選択する
    3. 「空のプロジェクト」を選択して「次へ」をクリックする
    4. プロジェクト名（例: HelloWorld）と保存場所を設定し、「作成」をクリックする

    ソースファイルの追加

    1. ソリューションエクスプローラーで「ソースファイル」フォルダを右クリックする
    2. 「追加」→「新しい項目」を選択する

    3. 「C++ ファイル (.cpp)」を選び、ファイル名を hello.c に変更して「追加」をクリックする

      拡張子を .c にする

      ファイル名の拡張子を .c にすることで、C++ ではなく C としてコンパイルされる。本講義では C を使用するため、拡張子は .c とすること。

    4. 以下のコードを入力する：

      #include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}

    コンパイルと実行

    1. メニューバーの「ビルド」→「ソリューションのビルド」を選択する（ショートカット: ++ctrl+shift+b++）
    2. ビルドが成功したら「デバッグ」→「デバッグなしで開始」を選択する（ショートカット: ++ctrl+f5++）
    3. コンソールウィンドウに Hello, World! と表示されれば成功である

    コンパイルオプションの設定

    警告レベルを上げたい場合は、プロジェクトのプロパティから設定できる：

    1. ソリューションエクスプローラーでプロジェクトを右クリック →「プロパティ」
    2. 「C/C++」→「全般」→「警告レベル」を「レベル4 (/W4)」に変更する

    演習用プロジェクトの管理

    各回の演習では、新しいプロジェクトを作成するか、既存プロジェクトのソースファイルを差し替えて使用する。

    • 方法1: 演習ごとに新しいプロジェクトを作成する
    • 方法2: 1つのプロジェクトでソースファイルを入れ替える（古いファイルを「除外」してから新しいファイルを追加）

    環境構築が完了したら、動作確認 に進むこと。
