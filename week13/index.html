    第13回: 高速フーリエ変換とスペクトル法

    今回の目標

    • 離散フーリエ変換（DFT, discrete Fourier transform）を定義し、定義どおりに計算すると \(O(N^2)\) の演算が必要なことを確認する
    • クーリー＝テューキー法（Cooley–Tukey algorithm）——偶数番目と奇数番目に分けて再帰する分割統治——により \(O(N\log N)\) に落ちる仕組みを説明でき、再帰版の高速フーリエ変換（FFT, fast Fourier transform）を自分で書けるようになる
    • 実務で使う FFTW ライブラリの呼び出し方を知る
    • フーリエ微分——\(\hat u_k\) を \(\mathrm{i}k\hat u_k\) に置き換えるだけで微分になる——を実装し、滑らかな周期関数に対する誤差がべきではなく指数で落ちること（スペクトル精度）を数値で確かめられるようになる
    • エイリアシング（aliasing）が起きる理由と、非線形項に対する 2/3 ルールによる除去法を説明できるようになる
    • 周期境界の拡散方程式・移流方程式をスペクトル法で解き、第9回・第11回の差分法と精度を直接比較できるようになる

    これまでの微分は「隣を見る」ものだった

    第7回以降、微分はすべて差分で置き換えてきた。\(u'(x_i)\approx(u_{i+1}-u_{i-1})/2\Delta x\) のように、近くの数点だけを見て傾きを推定する方法である。テイラー展開から誤差が \(O(\Delta x^2)\) や \(O(\Delta x^4)\) と分かり、格子を2倍細かくすれば誤差は \(1/4\)、\(1/16\) になった。これが代数的収束である。

    本回で扱うのは、まったく違う発想である。周期関数 \(u(x)\) を

    \[ u(x) \;=\; \sum_{k} \hat u_k\,e^{\mathrm{i}kx} \]

    と三角関数の重ね合わせで表しておけば、微分は

    \[ u'(x) \;=\; \sum_{k} (\mathrm{i}k)\,\hat u_k\,e^{\mathrm{i}kx} \]

    ——つまり係数に \(\mathrm{i}k\) を掛けるだけである。近似はどこにもない。近似が入るのは「有限個の \(k\) で打ち切る」ところだけで、滑らかな周期関数では \(\hat u_k\) が非常に速く小さくなるため、打ち切り誤差も非常に小さい。これがスペクトル法（spectral method）であり、その精度はスペクトル精度（spectral accuracy）あるいは無限次精度と呼ばれる。

    「非常に速く」の中身は関数の滑らかさで決まる。\(C^\infty\) 級なら誤差は \(N\) のどんな冪よりも速く落ちる（超代数的収束）が、\(e^{-aN}\) のように指数的に落ちるには、実軸を含む複素領域で解析的であることまで必要である。本回の主役 \(e^{\sin x}\) は整関数なので指数収束する（理由は微分のページで詳しく見る）。以下、断りなく「指数的」と書くときはこの解析的な場合を指す。

    差し引きは明快である。

    差分法 スペクトル法
    微分の作り方 近傍数点の線形結合 全点を使う（大域的）
    誤差の減り方 \(O(\Delta x^p)\)（代数的） \(\hat u_k\) の減り方に従う（滑らかなら指数的）
    1回の微分の計算量 \(O(N)\) \(O(N\log N)\)
    境界条件 ほぼ何でも扱える 周期境界が前提（非周期はチェビシェフ多項式）
    不連続がある場合 局所的に精度が落ちるだけ 領域全体に振動が出る（ギブス現象）

    「全点を使う」と聞くと \(O(N^2)\) の計算に思えるが、そこを \(O(N\log N)\) にするのが FFT である。FFT がなければスペクトル法は実用にならなかった——本回で FFT とスペクトル法を1つの回にまとめているのは、この依存関係のためである。

    第9回の安定性解析は、実は離散フーリエ変換だった

    新しい話に見えるが、フーリエ的な考え方はすでに何度も使っている。

    第9回のフォン・ノイマン安定性解析では、数値解に \(u^n_j=G^n e^{\mathrm{i}\theta j}\) を代入して増幅率 \(G(\theta)\) を調べた。これは「解を格子上の三角関数に分解し、モードごとに時間発展を見る」という操作そのものである。第11回の数値拡散・数値分散で \(\lvert G\rvert\) と \(\arg G\) を波数ごとに描いたのも、第9回の半離散化の固有値が \(\sin\) の形をしていたのも、すべて背景に離散フーリエ変換がある。

    違いは、それを紙の上の道具として使うか、計算の中で実際に実行するかである。本回では後者に踏み込む。毎ステップ実際に \(\hat u_k\) を計算し、フーリエ空間で微分し、実空間に戻す。第9回で「モードごとに \(e^{-\alpha k^2t}\) で減衰する」と紙の上で書いたことを、プログラムがそのまま実行する。

    記号の約束

    以降、区間は \([0,2\pi)\) とし、\(N\) 等分した格子点を

    \[ x_j = \frac{2\pi j}{N},\qquad j=0,1,\dots,N-1 \]

    とする。周期境界なので \(x_N=x_0\) であり、端点は片方だけを格子に含める（第9回〜第12回の \([0,1]\) で両端を含めたのと異なる点に注意する）。離散フーリエ変換とその逆変換を

    \[ \hat u_k = \sum_{j=0}^{N-1} u_j\,e^{-\mathrm{i}kx_j} = \sum_{j=0}^{N-1} u_j\,e^{-2\pi\mathrm{i}jk/N}, \qquad u_j = \frac{1}{N}\sum_{k=0}^{N-1}\hat u_k\,e^{+2\pi\mathrm{i}jk/N} \]

    と定義する（\(1/N\) を逆変換側に置く流儀を採る）。波数 \(k\) は \(0,1,\dots,N-1\) の範囲で計算されるが、\(e^{2\pi\mathrm{i}jk/N}\) は \(k\) について周期 \(N\) なので、微分のときは

    \[ k = 0,\,1,\,\dots,\,\tfrac{N}{2}-1,\;-\tfrac{N}{2},\,\dots,\,-1 \]

    と後半を負の波数として読み替える。この読み替えが本回のあらゆる場面で効いてくる。

    本章を貫く3つの例題

    例題1: \(u(x)=e^{\sin x}\) の微分（主役）

    \[ u(x) = e^{\sin x}, \qquad u'(x) = \cos x\;e^{\sin x} \]

    \(2\pi\) 周期で、しかも複素平面全体で解析的（整関数）である。この2つが揃うとフーリエ係数は \(k\) の指数関数より速く減る（実測では \(\lvert\hat u_{12}\rvert/N\approx5\times10^{-13}\)）。厳密な導関数が初等関数で書けるので、誤差をそのまま測れる。

    主役に選んだ理由は、差分法とスペクトル法の差がもっとも露骨に出るからである。同じ \(N\) に対して、2次中心差分・4次中心差分・スペクトル微分の誤差を並べると、前2者が \(N^{-2}\)・\(N^{-4}\) で下がる横で、スペクトル微分だけが \(N=32\) で丸め誤差の水準に到達する。

    例題2: ノイズに埋もれた合成信号

    \[ f(t) = \sin(2\pi\cdot5\,t) + 0.5\sin(2\pi\cdot12\,t) + (\text{振幅 }0.8\text{ の一様乱数}) \]

    第1回で紹介した FFT によるノイズ除去の実体である。信号は少数の波数に集中するが、ノイズは全波数に薄く広がる。したがってスペクトルを見てしきい値以下の成分を \(0\) にし、逆変換で戻せば信号が浮かび上がる。微分方程式とは関係がないが、FFT の使われ方としてはむしろこちらが主流であり、「基底を変えると問題が簡単になる」という本回の主題を最短で示す例でもある。

    例題3: 周期境界の拡散と移流

    \[ \frac{\partial u}{\partial t} = \nu\frac{\partial^2u}{\partial x^2}, \qquad\qquad \frac{\partial u}{\partial t} + c\,\frac{\partial u}{\partial x} = 0 \qquad (x\in[0,2\pi),\ \text{周期境界}) \]

    フーリエ変換すると、どちらも各波数が独立な1階の常微分方程式になる。

    \[ \frac{d\hat u_k}{dt} = -\nu k^2\,\hat u_k \quad\Longrightarrow\quad \hat u_k(t)=\hat u_k(0)\,e^{-\nu k^2t}, \qquad \frac{d\hat u_k}{dt} = -\mathrm{i}ck\,\hat u_k \quad\Longrightarrow\quad \hat u_k(t)=\hat u_k(0)\,e^{-\mathrm{i}ckt} \]

    拡散は減衰（実の負の固有値）、移流は位相の回転（純虚の固有値）——第6回の試験方程式の \(\lambda\) が、そのまま実軸上と虚軸上に現れる。第9回と第11回で別々に扱った2つの方程式が、フーリエ空間では同じ形の ODE の実部・虚部の違いでしかないことが見える。

    拡散のほうは \(\hat u_k\) の式が厳密解そのものなので、時間積分の誤差すら入らない。移流は、後述の非線形問題との比較のため RK4 で時間を進め、第11回の風上差分・ラックス＝ウェンドロフ法と同じ設定（クーラン数 \(0.5\)、1周させる）で比べる。

    スペクトル法が万能でない2つの場面

    (1) 非周期の境界条件。フーリエ基底は周期関数の基底なので、\(u(0)=u(2\pi)\) でない問題にそのまま使うと、端で不連続を扱うことになり全域に振動が出る。この場合はチェビシェフ多項式を基底に取る（チェビシェフ・スペクトル法。本講義では扱わないが、離散コサイン変換として FFT がそのまま使える）。

    (2) 解に不連続や折れ曲がりがある問題。衝撃波を含む流体計算などでは、フーリエ係数が \(1/k\) でしか減らず、精度の利点が消えるうえにギブス現象による振動が領域全体に広がる。演習3でこの弱点を数値で確認する。

    逆に言えば、周期境界かつ解が滑らかという条件が揃う問題——一様乱流の直接数値計算、周期構造をもつ材料の解析など——では、スペクトル法は同じ精度を差分法よりはるかに少ない格子点で達成する。
