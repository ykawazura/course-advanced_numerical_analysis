    演習問題

    解答について

    演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、解答が表示される。

    演習は、第5回の演習と同じ RK4 と AB4 のプログラムで解ける。書き換えるのは、右辺 f・厳密解 exact と、main で回すステップ数 \(N\) だけである。第5回は精度が \(h\) を決める問題で、AB4 が得だった。ここでは安定性が \(h\) を決める問題で同じ2手法を比べ、他の手法の安定性で述べた「RK4 の評価回数は AB4 の約 2.3 分の 1 で済む」を確かめる。

    演習

    テスト方程式 \(y'=\lambda y\)（\(\lambda=-100\)）を、\(y(0)=0.5\) から \(t=2\) まで解く。厳密解 \(y(t)=0.5\,e^{-100t}\) は \(t=0.1\) で \(2.3\times10^{-5}\) まで減り、\(y(2)\approx6.9\times10^{-88}\) は事実上 \(0\) である。この先の解はほとんど変わらないので、\(h\) を決めるのは精度ではなく安定性である。

    評価回数 \(n_f\) は第5回の演習と同じく RK4 を \(4N\)、AB4 を \(N\) と数え、AB4 の起動（RK4）の十数回は数えない。

    (a) RK4 と AB4 の絶対安定領域は、実軸上ではそれぞれ \(-2.785\lesssim z\le0\)、\(-0.3\le z\le0\) である（他の手法の安定性）。\(h=2/N\) のとき \(z=h\lambda\) がこの範囲に入る最小の \(N\) と、そのときの \(n_f\) を両手法で求め、\(n_f\) の比を求めよ。

    (b) RK4 を \(N=70,\ 72,\ \dots,\ 80\)、AB4 を \(N=650,\ 660,\ \dots,\ 700\) で解き、\(n_f\) と \(t=2\) での誤差 \(|y_N-y(2)|\) を表にせよ。誤差 \(10^{-8}\) 以下になる最小の \(N\) と \(n_f\) を両手法で求め、(a) の見積もりと比べよ。第5回の演習では、例題1（\(y'=y-t^2+1\)）を誤差 \(10^{-8}\) まで解くのに AB4 は 400 回、RK4 は 800 回の評価で済んだ。これと合わせて、RK4 と AB4 のどちらが得かは何で決まるかを答えよ。

    ヒント
    • rk4_step・rk4_at2 は第4回の精度の比較から、ab4_step・ab4_at2 は第5回の線形多段法のサンプルから、そのまま写せばよい。\(y(0)=0.5\) と \(t=2\) は rk4_at2・ab4_at2 に書き込まれているので、そのまま使える。
    • \(y(2)\) は事実上 \(0\) なので、誤差は数値解の大きさ \(|y_N|\) そのもので、数値解がどこまで減衰したかを表す。
