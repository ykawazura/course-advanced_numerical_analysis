    演習問題

    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    いずれの演習も、外側のニュートン反復（第2回）と内側の連立1次方程式の求解（第3回）を組み合わせて解く。多変数ニュートン法ページのサンプルの gauss_solve（部分ピボット選択つきガウスの消去法）と newton_sys_step（1回の更新）は、そのまま使うとよい（演習2では gauss_solve に特異判定を足す）。

    演習1（基礎）

    次の2つの円の交点を、多変数ニュートン法で求めよ。

    \[ \begin{cases} \ x^2 + y^2 = 2 & (\text{原点中心、半径 } \sqrt 2) \\ \ (x - 1)^2 + y^2 = 1 & (\text{中心 } (1,0)\text{、半径 } 1) \end{cases} \]

    初期値を \((x_0, y_0) = (2, 2)\) として、各反復の \(\|\mathbf{F}\|\) を表示し、厳密解と一致することを確認せよ。\(\|\mathbf{F}\|\) の減り方から収束次数を読み取れ。また、\(x\) 座標は最初の1反復で \(1\) になる。その理由を述べよ。

    ヒント
    • \(\mathbf{F}(\mathbf{x}) = \big(x^2 + y^2 - 2,\ (x-1)^2 + y^2 - 1\big)^{\top}\)。ヤコビ行列は \(J = \begin{pmatrix} 2x & 2y \\ 2(x-1) & 2y \end{pmatrix}\) である。
    • 2式を引き算すると \(x^2 - (x-1)^2 - 1 = 2x - 2\)。これは \(x\) について1次なので、交点の \(x\) 座標は \(x = 1\) とすぐ分かる。これを円に代入して \(y = \pm 1\)。厳密解は \((1, 1)\) と \((1, -1)\)。
    • 多変数ニュートン法ページのサンプルコードの F_eval と J_eval を書き換えるだけでよい。

    解答（🔒 パスワードを入力すると表示）

    演習2（応用）

    本章を貫く例題（円 \(x^2+y^2=4\) と双曲線 \(xy=1\)、解は4つ）について、初期値を変えながら多変数ニュートン法を実行し、どの解に収束するか、あるいは収束しないかを観察せよ。少なくとも次の初期値を試せ。

    \[ (2, 1),\ (1, 2),\ (-2, -1),\ (-1, -2),\ (2, 0.1),\ (0.1, 2),\ (1, 1),\ (0, 3) \]

    結果を多変数ニュートン法ページの収束領域の図と照らし合わせ、初期値依存について論ぜよ。とくに \((1, 1)\) で何が起こるか、その理由を述べよ。

    ヒント
    • 4つの解は A \((+1.932, +0.518)\)、B \((+0.518, +1.932)\)、C \((-1.932, -0.518)\)、D \((-0.518, -1.932)\) である。
    • 反復が発散することがある。|x| > 1e6 のような閾値で発散を検出し、無限ループを避けること。
    • \((1, 1)\) ではヤコビ行列 \(J = \begin{pmatrix} 2 & 2 \\ 1 & 1 \end{pmatrix}\) の行列式が \(0\) である。この意味を考えよ。
    • ガウス消去の側にもピボットがゼロかどうかの判定を入れること。 入れないと \(-1/0=-\infty\) が返り、次の反復で座標が巨大になって「発散」と誤って報告されてしまう。原因は発散ではなく \(J\) が特異であることなので、両者は区別して表示する。

    解答（🔒 パスワードを入力すると表示）

    演習3（応用）

    次の3変数の連立非線形方程式（数値解析の教科書で有名な例）を、多変数ニュートン法で解け。

    \[ \begin{cases} \ 3x - \cos(yz) - \dfrac{1}{2} = 0 \\[4pt] \ x^2 - 81\,(y + 0.1)^2 + \sin z + 1.06 = 0 \\[4pt] \ e^{-xy} + 20z + \dfrac{10\pi - 3}{3} = 0 \end{cases} \]

    初期値を \((0.1, 0.1, -0.1)\) とし、各反復で \(3 \times 3\) の連立1次方程式を解くこと。厳密解 \(\approx (0.5,\ 0,\ -\pi/6)\) と照合せよ。

    ヒント
    • ヤコビ行列の各成分は手で偏微分して求める。たとえば \(\partial F_1/\partial y = z\sin(yz)\)、\(\partial F_2/\partial y = -162(y+0.1)\)、\(\partial F_3/\partial z = 20\) など。
    • 内側のソルバ gauss_solve と1回の更新 newton_sys_step は \(n = 3\) でそのまま使える（次元 n を引数で受け取るので変更不要）。第3回のガウス消去法が3変数系でそのまま活きることを体感せよ。
    • \(\pi\) は M_PI（環境によっては未定義）に頼らず、定数 const double PI = 3.14159265358979323846; を自分で定義すると移植性が高い。

    演習4（発展）

    これまでヤコビ行列 \(J\) は手で偏微分して与えてきた。しかし複雑な \(\mathbf{F}\) では偏導関数を求めるのが大変だったり、そもそも \(\mathbf{F}\) が数値計算でしか得られず手で微分できないこともある。そこで、ヤコビ行列を前進差分で数値的に近似する。

    \[ J_{ij} = \frac{\partial F_i}{\partial x_j} \approx \frac{F_i(\mathbf{x} + h\,\mathbf{e}_j) - F_i(\mathbf{x})}{h} \qquad (\mathbf{e}_j \text{ は第 } j \text{ 単位ベクトル}) \]

    本章を貫く例題について、\(h = 10^{-7}\) で数値ヤコビアンを使ったニュートン法を実装し、解析ヤコビアンを使った場合と収束の速さ・最終精度を比較せよ。

    (a) 両者の \(\|\mathbf{F}\|\) の推移を比較せよ。

    (b) きざみ幅 \(h\) はどう選ぶべきか。大きすぎる・小さすぎるとそれぞれ何が問題か。

    (c) ヤコビ行列の評価が高コストな場合に有効な発展的手法を挙げよ。

    ヒント
    • 数値ヤコビアンは、\(j\) 列について \(\mathbf{x}\) の第 \(j\) 成分だけ \(h\) ずらして \(\mathbf{F}\) を1回評価すればよい。\(n\) 変数なら \(\mathbf{F}\) を \(n+1\) 回評価する。
    • \(h\) が大きいと差分が真の微分からずれる（打ち切り誤差）。小さすぎると \(F_i(\mathbf{x}+h\mathbf{e}_j) - F_i(\mathbf{x})\) の桁落ちで丸め誤差が増える。前進差分では \(h \sim \sqrt{\varepsilon_{\text{mach}}} \approx 10^{-8}\) あたりが目安。
    • キーワード: 減速（ダンピング）ニュートン法、準ニュートン法、Broyden 法。
