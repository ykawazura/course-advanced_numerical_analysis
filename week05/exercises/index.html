    演習問題

    解答について

    演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、解答が表示される。

    演習は、線形多段法と第4回の精度の比較のサンプルコードを土台にすればよい。数値解と厳密解の差を測り、手法やステップ数を変えたときの誤差と手間（\(f\) の評価回数）を比べるのがねらいである。

    演習

    例題1（\(y' = y - t^2 + 1\)、\(y(0) = 0.5\)、厳密解 \(y(t) = (t+1)^2 - \tfrac12 e^t\)）を \(t = 2\) まで解くとき、同じ精度に達するまでに右辺 \(f\) を何回評価するかで手法のコストを比べる。2次のホイン法・AB2 と4次の RK4・AB4 で、ステップ数を \(N = 100, 200, 400, 800, 1600\)（\(h = 2/N\)）と倍々に変えて解け。

    評価回数 \(n_f\) は次の表で数え、AB2・AB4 の起動（RK4）の十数回は \(N \gg 1\) なので数えない。

    手法 ホイン法 AB2 RK4 AB4
    評価回数 \(n_f\) \(2N\) \(N\) \(4N\) \(N\)

    (a) 各手法・各 \(N\) について、\(f\) の評価回数と \(t = 2\) での誤差 \(|y_N - y(2)|\) を表にせよ。

    (b) 誤差 \(10^{-8}\) 以下に最も少ない評価回数で達する手法はどれか。

    ヒント
    • ホイン法・RK4 の heun_step・rk4_step・heun_at2・rk4_at2 は第4回の精度の比較から、AB2・AB4 の ab2_step・ab4_step・ab2_at2・ab4_at2 は線形多段法のサンプルから、そのまま写せばよい。
