    演習問題

    解答について

    各演習には模範解答を用意してあるが、パスワードで保護されている。授業中に配布されるパスワードを入力すると、その問題の解答が表示される。問題ごとにパスワードは異なる。

    いずれの演習も、線形多段法・陰的解法のサンプルコードを土台にすればよい。数値解と厳密解の差を測り、刻み幅を変えたときの誤差比や安定性を観察するのが共通のねらいである。

    演習1（基礎）

    例題1（\(y' = y - t^2 + 1\)、\(y(0) = 0.5\)、厳密解 \(y(t) = (t+1)^2 - \tfrac12 e^t\)）を AB2（2段アダムス＝バッシュフォース法）

    \[ y_{n+1} = y_n + \tfrac{h}{2}\left(3 f_n - f_{n-1}\right) \]

    で \(h = 0.2,\ 0.1,\ 0.05\) の3通りで \(t = 2\) まで解け。起動の \(y_1\) は RK4 で作ること。

    (a) それぞれの \(t = 2\) での誤差と誤差比を求め、AB2 が2次精度である（刻みを半分にすると誤差が約 \(1/4\)）ことを確認せよ。

    (b) 第4回のホイン法（1ステップで \(f\) を2回評価）と比べ、AB2 は1ステップ \(f\) 評価1回で同じ2次精度であることを述べよ。

    ヒント
    • 線形多段法のサンプルコードの ab2_at2 をそのまま使い、\(h\) を変えて \(t=2\) の値だけ取り出せばよい。
    • 2次精度なら大域誤差は \(O(h^2)\) なので、\(h\) を半分にすると誤差は \(1/2^2 = 1/4\)、誤差比は約 \(4\) になる。
    • 起動には RK4 を1ステップだけ使う。最初の傾き \(f_{-1}\) は存在しないので、\(f_0, f_1\) を用意してから AB2 のループに入る。

    解答（🔒 パスワードを入力すると表示）

    演習2（基礎）

    例題1を後退オイラー法 \(y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})\) で \(h = 0.2\) として \(t = 2\) まで解け。ただし陰的方程式を不動点反復

    \[ Y^{(k+1)} = y_n + h\, f(t_{n+1}, Y^{(k)}), \qquad Y^{(0)} = y_n \]

    で解くこと（ニュートン法ではなく）。

    (a) 各ステップで不動点反復が何回で収束するか（収束判定 \(|Y^{(k+1)}-Y^{(k)}|<10^{-12}\)）を表示せよ。

    (b) \(h = 0.2,\ 0.1,\ 0.05\) で \(t=2\) の誤差比を求め、後退オイラーが1次精度であることを確認せよ。

    ヒント
    • 不動点反復は \(h\,|\partial f/\partial y| = h \cdot 1 = h < 1\) なら収束する。\(h=0.2\) なら収束するが、\(h\) が小さいほど収束は速い。
    • 陰的解法のサンプルコードの後退オイラーをニュートン法から不動点反復に置き換えるだけでよい。
    • 不動点反復はニュートン法より収束が遅い（1次収束）ので、反復回数は数回〜十数回になる。回数を数えて比べてみよ。

    解答（🔒 パスワードを入力すると表示）

    演習3（応用）

    例題2の硬い問題 \(y' = -\lambda y\)（\(y(0)=1\)、厳密解 \(e^{-\lambda t}\)）を \(\lambda = 50\) として、前進オイラー法と後退オイラー法で \(t = 1\) まで解け。両手法とも線形なので、増幅率の累乗で終端値が書ける（前進 \((1-\lambda h)^N\)、後退 \(1/(1+\lambda h)^N\)）。

    (a) 刻み幅を \(h = 0.01,\ 0.03,\ 0.05,\ 0.10\) と変え、前進オイラーが安定限界 \(h < 2/\lambda = 0.04\) を境に発散することを実験的に確認せよ。

    (b) 同じ \(h\) で後退オイラーが無条件に安定（どの \(h\) でも \(0\) へ減衰）であることを示せ。

    ヒント
    • 前進オイラーの増幅率は \(1-\lambda h\)。\(|1-\lambda h|<1 \Leftrightarrow 0<h<2/\lambda\)。\(\lambda=50\) なら \(h<0.04\)。
    • \(h=0.03\)（\(\lambda h=1.5\)）では増幅率 \(|{-0.5}|<1\) で安定、\(h=0.05\)（\(\lambda h=2.5\)）では \(|{-1.5}|>1\) で発散する。
    • 後退オイラーの増幅率 \(1/(1+\lambda h)\) は \(h>0\) なら常に \(0<r<1\)。

    演習4（発展）

    台形則（＝アダムス＝ムルトン AM1）\(y_{n+1} = y_n + \tfrac h2(f_n + f_{n+1})\) を実装する。

    (a) 例題1に適用し、\(h = 0.2,\ 0.1,\ 0.05\) の誤差比から台形則が2次精度であることを確認せよ。例題1は \(f\) が \(y\) について線形なので、陰的方程式は反復せず直接解ける（下記ヒント）。

    (b) 例題2の硬い問題（\(\lambda = 50,\ h = 0.1\)、すなわち \(\lambda h = 5 > 2\)）で台形則と後退オイラーの増幅率と値の推移を比べ、台形則は有界だが符号が振動する一方、後退オイラーは単調減衰することを示せ。「無条件に有界でも振動は起こりうる」点を論ぜよ。

    ヒント
    • (a) 例題1では \(f(t,y)=y-t^2+1\) が \(y\) について線形なので、\(Y = y_n + \tfrac h2(f_n + (Y - t_{n+1}^2 + 1))\) を \(Y\) について解くと \(Y(1-\tfrac h2) = y_n + \tfrac h2(f_n + 1 - t_{n+1}^2)\)。反復不要で1行で書ける。
    • (b) 台形則の増幅率は \(\dfrac{1-\lambda h/2}{1+\lambda h/2}\)。\(\lambda h = 5\) なら \(\dfrac{1-2.5}{1+2.5} = -\dfrac{1.5}{3.5} \approx -0.43\)。絶対値は \(1\) 未満（有界）だが負なので符号が交代する。
    • 後退オイラーの増幅率 \(1/(1+\lambda h) = 1/6 \approx 0.167\) は正で単調。
