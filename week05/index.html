    第5回: 常微分方程式の初期値問題（多段法・陰的解法）

    今回の目標

    • 過去の複数点の情報を使って効率よく高次精度を得る線形多段法（linear multistep method）——とくに陽的なアダムス＝バッシュフォース法と陰的なアダムス＝ムルトン法——を理解し、実装できるようになる
    • 未来の値を方程式に含む陰的解法（implicit method）——後退オイラー法と台形則——を導出し、陰的方程式を反復（不動点反復・ニュートン法）で解けるようになる
    • 硬い（stiff な）問題で陽解法が刻み幅に厳しい制約を受けて発散する一方、陰的解法が無条件に安定であることを数値実験で体感し、陰的解法の必要性を理解する
    • 陽的予測と陰的修正を組み合わせる予測子修正子法（predictor–corrector method）の考え方を理解し、第4回のホイン法がその最も簡単な例であることを知る

    第4回の復習：1段法とその限界

    第4回では、\(y_n\) から \(y_{n+1}\) を求めるのに直前の1点だけを使う1段法（one-step method）を学んだ。前進オイラー法（1次）、ホイン法（2次）、RK4（4次）である。ルンゲ＝クッタ法は精度を上げるために、1ステップの内部で右辺 \(f\) を複数回評価していた（RK4 は4回）。これは確実だが、\(f\) の評価が高価な問題ではコストがかさむ。

    また、これらはすべて陽的（explicit）な方法であった。すなわち \(y_{n+1}\) が既知量だけの式で直接書けた。陽解法は手軽だが、安定性に刻み幅の制約がある。第4回の調和振動子でも、前進オイラー法はエネルギーが系統的に増大して解が破綻した。後述の硬い問題では、この制約はさらに深刻になる。

    1段法を拡張する2つの軸

    第5回では、1段法・陽解法を2つの異なる方向に拡張する。

    1. 過去を使い回す——線形多段法：1段法は過去の点を捨てていたが、すでに計算した過去の傾き \(f_{n-1}, f_{n-2}, \dots\) を蓄えて再利用すれば、1ステップあたり \(f\) の評価1回のまま高次精度が得られる。これが線形多段法（アダムス法）である。→ 線形多段法

    2. 未来を方程式に含む——陰的解法：陽解法は \(y_{n+1}\) を直接書けたが、右辺に未知の \(y_{n+1}\) 自身を含めると、毎ステップ方程式を解く手間が増える代わりに、はるかに安定な解法（後退オイラー法・台形則）が得られる。硬い問題に不可欠である。→ 陰的解法

    そして、陰的解法の「方程式を解く」手間を、陽的な予測値で近似的に省くのが予測子修正子法である。→ 予測子・修正子法

    1段／多段 陽的／陰的 1ステップの \(f\) 評価 精度
    前進オイラー（第4回） 1段 陽的 1回 1次
    RK4（第4回） 1段 陽的 4回 4次
    AB2 / AB4 多段 陽的 1回 2次 / 4次
    後退オイラー 1段 陰的 （反復） 1次
    台形則 1段 陰的 （反復） 2次

    本章を貫く2つの例題

    第4回の例題1を精度の検証にそのまま引き継ぎ、陰的解法の動機づけのために硬い問題を新たに例題2として導入する。

    例題1: 厳密解のあるスカラー問題（第4回から継続）

    \[ y' = y - t^2 + 1, \qquad y(0) = 0.5, \qquad t \in [0, 2]. \]

    厳密解は

    \[ y(t) = (t+1)^2 - \tfrac{1}{2} e^{t}, \qquad y(2) = 9 - \tfrac{1}{2} e^2 \approx 5.305472. \]

    厳密解が分かるので、多段法・予測子修正子法の収束次数を誤差比で定量的に確認できる。第4回の RK4（\(h=0.2\) で誤差 \(1.1\times10^{-4}\)）とも直接比較できる。

    例題2: 硬い問題（新規・stiff）

    \[ y' = -\lambda y, \qquad y(0) = 1, \qquad \lambda > 0 \ (\text{大きい}). \]

    厳密解は \(y(t) = e^{-\lambda t}\) で、\(\lambda\) が大きいほど急速になめらかに減衰する。本ページでは \(\lambda = 20\) を主に用いる。

    この問題は線形で答えが分かりきっているが、数値解法の安定性を浮き彫りにする格好の題材である。前進オイラー法を適用すると

    \[ y_{n+1} = (1 - \lambda h)\, y_n \]

    となり、増幅率 \(|1 - \lambda h| < 1\)、すなわち刻み幅が \(h < 2/\lambda\) でなければ振動・発散してしまう。解そのものはなめらかに \(0\) へ減衰するのに、精度ではなく安定性のために刻みを極端に小さくせざるを得ない——これが硬さ（stiffness）である。一方、後退オイラー法 \(y_{n+1} = y_n/(1+\lambda h)\) は任意の \(h>0\) で単調減衰し（無条件安定）、台形則 \(y_{n+1} = \frac{1-\lambda h/2}{1+\lambda h/2}\,y_n\) は有界だが \(\lambda h > 2\) で符号が振動する。陰的解法の必要性を可視化する中心的な例題である。

    安定性の本格的な議論は第6回

    本回では硬い問題を陰的解法の動機づけとして扱い、「陽解法は \(h<2/\lambda\) の制約を受ける／陰的解法は無条件に安定」という定性的な事実までを数値で確かめる。増幅率を複素平面で考える絶対安定領域や A安定性 の正式な定義は、次回の第6回「安定性解析」で詳しく扱う。
