    演習1（基礎）

    二分法を用いて、次の方程式の根を求めよ。

    \[ f(x) = e^x - 3x = 0 \]

    (a) 区間 \([0, 1]\) で根を求めよ。

    (b) 区間 \([1, 2]\) で根を求めよ。

    各反復における近似値 \(c\)、\(f(c)\) の値、区間幅を表示するようにプログラムを作成し、収束の様子を観察せよ。

    ヒント
    • \(f(0) = 1 > 0\)、\(f(1) = e - 3 \approx -0.28 < 0\) なので区間 \([0, 1]\) に根が存在する。
    • \(f(1) \approx -0.28 < 0\)、\(f(2) = e^2 - 6 \approx 1.39 > 0\) なので区間 \([1, 2]\) にも根が存在する。
    • C で指数関数を使うには #include <math.h> と exp() 関数を使い、コンパイル時に -lm オプションを付ける。
    • 二分法のサンプルコードの f(x) の定義を変更し、区間を適切に設定すればよい。

    解答（🔒 パスワードを入力すると表示）

    演習2（基礎）

    ニュートン法を用いて、次の方程式の根を求めよ。

    \[ f(x) = \cos(x) - x = 0 \]

    以下の異なる初期値で実行し、収束の違いを確認せよ。

    • \(x_0 = 0\)
    • \(x_0 = 1\)
    • \(x_0 = 3\)
    ヒント
    • 導関数は \(f'(x) = -\sin(x) - 1\) である。
    • \(f'(x) = -\sin(x) - 1 \leq 0\) なので、\(f'(x) = 0\) となるのは \(\sin(x) = -1\) すなわち \(x = -\frac{\pi}{2} + 2n\pi\) のときのみである。初期値がこれらの点に近くなければ問題なく収束する。
    • 根は \(x \approx 0.7391\) 付近に存在する。

    解答（🔒 パスワードを入力すると表示）

    演習3（応用）

    次の方程式を二分法、ニュートン法、はさみ打ち法の3つの方法で解け。

    \[ f(x) = x - \cos(x) = 0 \]

    各手法について以下を記録し、結果を表にまとめよ。

    • 反復回数
    • 最終的な近似根

    条件：

    • 許容誤差: \(\varepsilon = 10^{-10}\)
    • 二分法・はさみ打ち法の初期区間: \([0, 1]\)
    • ニュートン法の初期値: \(x_0 = 0.5\)
    ヒント
    • 導関数は \(f'(x) = 1 + \sin(x)\) である。
    • \(f(0) = 0 - \cos(0) = -1 < 0\)、\(f(1) = 1 - \cos(1) \approx 0.46 > 0\) なので区間 \([0, 1]\) に根が存在する。
    • 3つの手法で同じ f(x) を共有し、出力形式を統一すると比較しやすい。
    • 結果の表には、手法名、反復回数、近似根の値を含めること。
