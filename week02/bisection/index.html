    二分法

    二分法（bisection method）は、中間値の定理に基づく最も基本的な求根法である。

    原理

    連続関数 \(f(x)\) に対して、\(f(a)\) と \(f(b)\) が異符号、すなわち \(f(a) \cdot f(b) < 0\) であれば、中間値の定理により区間 \((a, b)\) 内に少なくとも1つの根が存在する。

    二分法では、区間の中点 \(c = \frac{a + b}{2}\) における \(f(c)\) の符号を調べ、根を含む側の半区間を選択することで、根を囲む区間を半分ずつ狭めていく。

    アルゴリズム

    入力: 関数 f, 区間 [a, b] (f(a)·f(b) < 0), 許容誤差 ε, 最大反復回数 N
出力: 近似根 c

for n = 1, 2, ..., N:
    c = (a + b) / 2
    if |f(c)| < ε or (b - a)/2 < ε:
        return c
    if f(a)·f(c) < 0:
        b = c
    else:
        a = c
return c  （収束しなかった場合）

    収束性

    二分法の収束次数は1次（線形収束）である。\(n\) 回の反復後、近似根の誤差は以下で抑えられる：

    \[ |e_n| \leq \frac{b - a}{2^n} \]

    したがって、所望の精度 \(\varepsilon\) を達成するために必要な反復回数は：

    \[ n \geq \frac{\log(b - a) - \log(\varepsilon)}{\log 2} \]

    で見積もることができる。

    サンプルコード

    例題として \(f(x) = x^3 - x - 2 = 0\) の根を区間 \([1, 2]\) で求める。

    #include <stdio.h>
#include <math.h>

/* f(x) = x^3 - x - 2 */
double f(double x)
{
    return x * x * x - x - 2.0;
}

int main(void)
{
    double a = 1.0, b = 2.0;   /* 探索区間 */
    double c;                    /* 中点 */
    double eps = 1.0e-10;        /* 許容誤差 */
    int max_iter = 100;          /* 最大反復回数 */
    int n;
    FILE *fp;                    /* 作図用データの出力先 */

    /* f(a) と f(b) の符号が異なることを確認 */
    if (f(a) * f(b) >= 0.0) {
        printf("エラー: f(a) と f(b) が同符号である\n");
        return 1;
    }

    fp = fopen("bisection.dat", "w");
    if (fp == NULL) {
        perror("bisection.dat");
        return 1;
    }
    fprintf(fp, "# n c f(c) width\n");

    printf("%3s %20s %20s %20s\n", "n", "c", "f(c)", "区間幅");

    for (n = 1; n <= max_iter; n++) {
        c = (a + b) / 2.0;

        printf("%3d %20.15f %20.15e %20.15e\n", n, c, f(c), b - a);
        fprintf(fp, "%d %.15e %.15e %.15e\n", n, c, f(c), b - a);

        if (fabs(f(c)) < eps || (b - a) / 2.0 < eps) {
            printf("\n近似根: %.15f\n", c);
            printf("反復回数: %d\n", n);
            fclose(fp);
            return 0;
        }

        if (f(a) * f(c) < 0.0) {
            b = c;
        } else {
            a = c;
        }
    }

    printf("警告: 最大反復回数に達した\n");
    printf("現在の近似根: %.15f\n", c);
    fclose(fp);
    return 0;
}

    コンパイルと実行：

    gcc -Wall -O2 -o bisection bisection.c -lm
./bisection

近似根: 1.521379706799053

    3列目の区間幅がきっかり半分ずつ（\(1.0 \to 0.5 \to 0.25 \to \cdots\)）減っているのが二分法の本質である。誤差は反復ごとに一定の割合でしか縮まないので、有効数字を10桁得るのに33回かかった。

    2列目の \(f(c)\) の符号が \(-,+,+,+,+,-,+,-,\ldots\) と不規則に入れ替わるのは、中点が根の左右に交互に来るためで、収束の履歴を対数目盛で描くとはさみ打ち法のページの図のような鋸歯状になる。

    なお、このプログラムが33回で止まったのは \(|f(c)| < \varepsilon\) の条件が先に満たされたからである。区間幅の条件だけで判定すると、上の見積もり \(n \geq \dfrac{\log(b-a) - \log\varepsilon}{\log 2} = \dfrac{\log 1 - \log 10^{-10}}{\log 2} = 33.2\) のとおり34回を要する。

    可視化

    bisection.c は表を標準出力に出すのと同時に、同じ値を bisection.dat にも書き出す（1列目が反復回数 \(n\)、2列目が中点 \(c_n\)、3列目が \(f(c_n)\)、4列目が区間幅 \(b-a\)）。これを Python で読んで、区間幅と \(|f(c_n)|\) の減り方を対数目盛で描く。

    必要なパッケージ

    作図には NumPy と Matplotlib を使う。入っていなければ pip install numpy matplotlib（第1回の Docker 環境にはすでに入っている）。図中の文字は日本語フォントが無い環境では豆腐（□）になるので、軸ラベルと凡例は英語にしてある。

    import numpy as np
import matplotlib.pyplot as plt

n, c, fc, width = np.loadtxt("bisection.dat", unpack=True)

fig, ax = plt.subplots(figsize=(6.5, 4.5))
ax.semilogy(n, width, "o-", ms=4, label="interval width $b-a$")
ax.semilogy(n, np.abs(fc), "s-", ms=4, label="$|f(c_n)|$")
ax.semilogy(n, 2.0 ** (1 - n), "k--", lw=1, label="$2^{-(n-1)}$")
ax.set_xlabel("iteration $n$")
ax.set_ylabel("magnitude")
ax.set_title("Bisection: the interval halves at every step")
ax.grid(alpha=0.3)
ax.legend()
fig.tight_layout()
fig.savefig("bisection.png", dpi=150)
plt.show()

    実行:

    python3 plot_bisection.py

    区間幅が基準線 \(2^{-(n-1)}\) にぴったり重なり、\(|f(c_n)|\) がその周りで鋸歯状に振動しながら同じ傾きで落ちていくのが見える。対数目盛で直線＝一定の比で縮む、これが1次収束の見え方である。

    利点と欠点

    利点:

    • 実装が簡単である
    • \(f(a) \cdot f(b) < 0\) が成り立つ限り、必ず収束する
    • 必要な反復回数を事前に見積もれる

    欠点:

    • 収束が遅い（1次収束）
    • 初期区間 \([a, b]\) で \(f(a) \cdot f(b) < 0\) を満たす必要がある
    • 区間内に複数の根がある場合、そのうちの1つしか求められない
